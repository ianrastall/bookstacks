# Bookstacks conventions

Follow ../AGENTS.md and ../_standards/. Ian authorizes commits, pushes, pulls and releases. Preserve canonical TEI, edition/language identities, reader URLs, source credits, notes and approved portraits. Keep XML and PDF publication pipelines distinct; site deployment must not regenerate the corpus or PDFs. Use Astro/TypeScript, semantic CSS tokens and the Jupiter appearance controls. Use plain functional copy without promotional blurbs. Validate changes before publishing.

Keep the library unified across book languages. Interface locale follows browser preferences or an explicit user choice; it must never filter the catalogue or silently switch the selected edition/chapter. Preserve source language metadata independently from interface language.

Set the first prose paragraph of each section, including each reader page, flush left. Set epigraphs, epigrams and chapter arguments in italic, left-aligned text inside a centered block inset 2em on both sides.

For Shakespeare, center entrances and right-align exits. Set stage direction text in italics inside upright square brackets, with character names upright and uppercase. Keep other directions inline in the character's part when attributable. Put each upright uppercase speaker label directly above the speech with zero space below the label. Use the same inset treatment for songs as for chapter arguments. Leave one blank line between stanzas and preserve only source-marked verse indentation.

Apply these rules to the online reader and downloadable PDFs. Preserve canonical TEI and source wording. Use the shared drama layout rules and character index for presentation.
