# Bookstacks conventions

Follow ../AGENTS.md and ../_standards/. Ian authorizes commits, pushes, pulls and releases. Preserve canonical TEI, edition/language identities, reader URLs, source credits, notes and approved portraits. Keep XML and PDF publication pipelines distinct; site deployment must not regenerate the corpus or PDFs. Use Astro/TypeScript, semantic CSS tokens and the Jupiter appearance controls. Use plain functional copy without promotional blurbs. Validate changes before publishing.

Keep the library unified across book languages. Interface locale follows browser preferences or an explicit user choice; it must never filter the catalogue or silently switch the selected edition/chapter. Preserve source language metadata independently from interface language.
