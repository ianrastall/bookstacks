# Christie source and artwork records

Seventeen canonical English TEI editions, 363 illustrated reading pages.
See [the edition record](../../docs/christie-editions.md) for contents, source
edition distinctions, retained material and offline import instructions.

- `selection.json`: pinned source HTML URLs and SHA-256 hashes, source credits,
  expected reading-unit counts and original figure records.
- `import-report.json`: per-unit text preservation checks.
- `illustration-plan.json`: one sketch subject and opening excerpt per page.
- `illustrations.json` and `art-records/`: exact prompts and image provenance.
- `img/`: delivery sketches, previews and original source figures.

The importer and artwork preparation are explicit offline commands outside
the website and PDF publication pipelines. The existing author portrait is
unchanged.
